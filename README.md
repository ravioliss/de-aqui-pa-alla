# 🚀 Rest. De Aquí para Allá

Este proyecto es un rediseño de una página web estática para un restaurante de comida internacional. Quiero mejorar la eficiencia de la página y hacer el código uno más limpio (clean code) usando metodología BEM.

## 📖 Descripción

Este proyecto es una **reescritura completa** del proyecto para el restaurante De aquí para allá con el objetivo de mejorar:

- ⚡ Rendimiento y velocidad de carga
- 🎨 Diseño responsive y accesibilidad
- 🧩 Código más limpio y mantenible
- 🔒 Mayor seguridad

---

## ✨ Características principales

- ✅ Código más limpio y organizado
- ✅ Menos repetición de archivo (síntesis)
- ✅ Mejora en la lectura y navegación en dispositivos móviles.
